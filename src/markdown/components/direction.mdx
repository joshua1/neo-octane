## Usage

Base UI popups (Popover, Tooltip, Menu, Select, ...) do not read the `dir` attribute of the document. Instead, they take the reading direction from `DirectionProvider`, which is what makes `side="inline-start"` / `side="inline-end"` positioning, keyboard navigation and RTL specific animations flip correctly. Wrap your app (or the part of it that is right-to-left) in the provider and set the `dir` attribute on the same element so the DOM matches.

```ts
import { ArrowLeftIcon, ArrowRightIcon } from '@octanejs/lucide'

import { Button } from '@/components/ui/button.tsrx'
import { DirectionProvider, useDirection } from '@/components/ui/direction.tsrx'
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from '@/components/ui/popover.tsrx'
```

```tsx
<DirectionProvider direction="rtl">
  <div dir="rtl">
    <Popover>
      <PopoverTrigger render={<Button />}>Open</PopoverTrigger>
      <PopoverContent side="inline-end">...</PopoverContent>
    </Popover>
  </div>
</DirectionProvider>
```

`DirectionProvider` and `useDirection` are re-exported from `@octanejs/base-ui/direction-provider`. Use the `useDirection` hook to read the current direction in your own components:

```tsx
function Arrow() @{
  const direction = useDirection()

  @if (direction === "rtl") {
    <ArrowLeftIcon />
  } @else {
    <ArrowRightIcon />
  }
}
```

See the <a target="_blank" href="https://base-ui.com/">Base UI documentation</a> for more details.
